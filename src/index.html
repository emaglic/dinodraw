What is Dino Draw?

Dino Draw is a local-first sketchbook for handwritten notes, sketches, and multi-page notebooks.

Documents

Local notebooks stored on this device.

Dino Draw Instructions

Local drawing, notebooks, and exports for pen-first tablets.

Start

  • Use New to create a local document.
  • Use Import to open a saved DinoDraw JSON file.
  • Open returns to the drawing canvas for a document.
  • The document menu handles rename, export, PNG, PDF, and delete.

Draw

  • Choose the pencil for drawing, eraser for erasing, square for shapes, or lasso for selection.
  • Tap a brush preset to select it. Double tap a preset to edit size, opacity, color, or Draw Behind.
  • Double tap the eraser tool to change eraser size.
  • Draw Behind places highlighter-style ink under normal writing.

Pages

  • Use the arrow buttons to move between pages.
  • Tap the page counter to browse thumbnails and manage pages.
  • Tap + to add a page before, after, or at the end of the document.
  • On supported browsers, volume up moves to the previous page and volume down moves to the next page.

Device Settings

  • Touch drawing is on by default so finger-only devices can draw right away.
  • Turn Touch drawing off from Settings when using a pen-first tablet to reduce palm marks.
  • Touch drawing is saved on this device, not inside each document.
  • Pen erasers, secondary buttons, and supported pen side buttons temporarily erase while drawing.

Settings And Files

  • Settings opens page paper, device settings, document actions, and toolbar reset.
  • Page Paper changes the current page background to blank, ruled, or graph.
  • Export saves an editable DinoDraw document file.
  • Save PNG and Save PDF create shareable flattened copies.

Toolbars

  • Drag a toolbar handle to move a toolbar.
  • Move a toolbar near an edge to change its orientation.
  • Use the tab at the screen edge to hide or show toolbars.
  • Reset Toolbars restores the default toolbar positions.
